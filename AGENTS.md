# SYNAX Telegram Bot Skill (`synax-telegram-bot`)

Provides remote Telegram Bot commands (`/status`, `/egraph`, `/prove`, `/check`, `/run`, `/code`) for **Claude Code**, **OpenAI Codex**, **Google Antigravity**, and **SYNAX**.

## Commands
- `python3 synax_telegram_bot.py --status`
- `python3 synax_telegram_bot.py --cmd "/egraph (a * b + 1.0) + (a - a)"`
- `python3 synax_telegram_bot.py --cmd "/prove relu(a - b)"`
- `python3 synax_telegram_bot.py --poll`
